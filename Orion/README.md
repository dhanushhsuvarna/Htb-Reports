
# HTB Reports

Penetration testing reports for retired Hack The Box machines. Each report covers enumeration, initial foothold, privilege escalation and remediation notes, written in the style of a VAPT report.

## Machines

| Machine | OS | Difficulty | Report |
|---------|----|-----------|--------|
| Orion | Linux | Easy | [Report](Orion/orion-report.pdf) |

## Structure

Each machine has its own folder with the report and its screenshots:

    MachineName/
    ├── report.pdf
    └── images/

## Disclaimer

These reports cover **retired** machines only, written for learning and documentation. Flags and password hashes are redacted. Only test systems you own or have written permission to test.
